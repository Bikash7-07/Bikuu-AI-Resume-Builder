# ✦ Bikuu AI — Resume Builder

Bikuu AI is a modern, AI-powered resume builder designed to help students, freshers, and professionals create clean, professional, and ATS-friendly resumes quickly.

## 🚀 Features

- ✨ Modern and responsive user interface
- 📄 Multiple professional resume templates
- 📝 Easy resume information form
- 👀 Real-time resume preview
- 🤖 Bikuu AI resume assistant
- 💡 AI-style suggestions for summaries, skills, and projects
- 📊 Resume completion progress
- 💾 Automatically saves resume data in the browser
- 📥 Print / Save resume as PDF
- 📱 Responsive design for mobile and desktop
- 🔗 Developer support through LinkedIn

## 🎨 Available Templates

Bikuu AI currently provides different resume styles:

- Modern
- Classic
- Minimal
- Student
- Creative

Users can select a template according to their career, profession, or personal preference.

## 🤖 Bikuu AI Assistant

The Bikuu AI assistant helps users improve their resume by providing suggestions for:

- Professional summaries
- Skills
- Projects
- Resume improvements
- General resume-building guidance

> Note: The current version uses a frontend-based chatbot demo. A real AI API can be integrated in a future version.
